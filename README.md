# bkeim-rewind-site

Marketing site for B Keim Rewind Marketing. Astro + Cloudflare Worker. See `CLAUDE.md` for setup,
deploy and form configuration.

```sh
npm install
npm run dev        # http://localhost:4321
npm run preview    # build + wrangler dev (Worker + form API) on :8787
npm run deploy     # build + wrangler deploy to *.workers.dev
```
